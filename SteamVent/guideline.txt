If the call HAS string arguments:
    - Declare the delegate parameter as IntPtr (not string); the native function receives a null-terminated UTF-8 char*
    - At the call site convert the managed string with Marshal.StringToCoTaskMemUTF8(...) and release it with Marshal.ZeroFreeCoTaskMemUTF8(...) after the call
      (the interface-getter version string is marshaled for you inside SteamInterfaceWrapper.GetInterface)
      For example, see 'ISteamClient017:GetISteamApps' (the delegate takes 'IntPtr pchVersion')

If the call RETURNS a string: 
    - The delegate return type should be IntPtr (not string)
    - The entire 'GetDelegate<>()' statement should be enclosed in 'DecodeUtf8String()', which reads the null-terminated
      UTF-8 string via Marshal.PtrToStringUTF8
      For example, see 'ISteamApps006:GetCurrentGameLanguage' ('DecodeUtf8String(GetDelegate<GetCurrentGameLanguageDelegate>()(InterfacePtr))')
